GET STARTED

Run it locally

  1. Use Python 3.10+ with SQLite FTS5.
  2. Set LLM_API_KEY and TAVILY_API_KEY or BRAVE_API_KEY in your terminal.
  3. Choose AGENT_USER and AGENT_DB.
  4. Run python server.py, then open this local address.

Restart the server after configuration changes. The README has full setup commands.

MEMORY

Continuity, not identity

SQLite stores user and assistant turns with UTC timestamps. Recent turns, keyword matches and a short question digest are sent to the model.

Your configured user id filters history; it is not login or authentication. Anyone with local access to the database can read it.

BOUNDARIES

Know what is verified

Answers are not streamed. Provider quotas can delay or stop requests. Domain matching does not verify an official source. Citation checks only remove URLs absent from returned results.

There is no claim of zero mistakes. The local tests do not establish real-model accuracy.
